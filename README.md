# Gada

gada flies on sky.

A lightweight Python utility designed for fast image extraction and smooth document processing.

Built for simplicity, portability, and quiet automation — gada focuses on handling visual documents with minimal user interaction and a clean workflow.

## Features

* Fast image extraction
* Batch processing support
* Lightweight workflow
* Simple drag-and-drop usage
* Minimal and clean interface
* Quiet background processing

## Requirements

* Python 3.10+
* Windows

## Notes

This project is intended for personal archiving, offline viewing, and workflow convenience.
